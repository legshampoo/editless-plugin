# Editless

The Editless tools come from the connected MCP server. Call `get_account` before any step that could spend videos. Call `list_campaigns` to see campaigns that already exist. Pass `pipeline` only when the person names UGC4, One Shot v2, or Ad Generator 1.

Follow the tool descriptions the server returns. Do not invent a video-generation procedure.
